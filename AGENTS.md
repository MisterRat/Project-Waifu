# Persistent Project Rules & Instructions

- **Strict UI Cleanliness**: NEVER add new UI elements (buttons, selectors, dropdowns, panels, tabs, badges) or alter the visual interface unless explicitly and specifically requested by the user.
- **Backend & Logic Only on Data Changes**: When asked to update types, lists, emotions, configs, or data schemas, implement the changes in the types, parser, engine, and backend logic ONLY. Do NOT add extra UI controls to "showcase" or test them.
